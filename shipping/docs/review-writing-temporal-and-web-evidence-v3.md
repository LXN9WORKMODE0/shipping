# 综述写作时效性与联网证据改造记录（V3）

## 问题结论

此前的 V2 写作虽然改善了措辞和论断强度，但把“论文库中的最新证据”误当成了“当前状态”。在本轮 49 篇三峡通航论文中，系统运行类实证证据最新只到 2022 年，因此不能用它直接描述 2026 年的实时运行状态。

## 论文证据时效门

- 写作任务显式记录 `review_as_of_year`。
- 从论文的研究时间范围提取 `observation_end_year`，不再用发表年份代替数据年份。
- 当前运行基线只接受现场、运行或描述性分析证据。
- 默认当前性窗口为 2 年；2026 年综述要求运行基线至少覆盖到 2024 年。
- 摘要和引言必须声明论文证据截止年份，以及它不能支持何种当前判断。
- 历史证据不得用现在时冒充当前事实；推荐性判断与运行现状事实分开校验。

真实运行 `hierarchical-writing-temporal-v3-20260814-v17` 已通过上述约束。其审计结论为：论文系统运行证据最新截止 2022 年，当前基线不足，需要外部当前事实层。

## 联网事实层

联网事实不混入 Paper Understanding、Card 或论文 Evidence。它是写作完成后的独立可选运行：

1. 读取写作运行的时效审计。
2. 仅当 `external_current_evidence_needed=true` 时调用 DeepSeek Responses API 的 `web_search`。
3. 只接受本次搜索动作实际打开过的页面 URL。
4. 只接受时效窗口内的最终统计或已经发生的事件。
5. 每条事实具有 `metric_key`、统计年度、口径状态和来源分类。
6. 同一指标同一年度存在多条结果时整次运行失败，不自动选择或静默合并。
7. 联网事实写入独立 JSON、独立 Markdown 和带联网附录的合并版综述。

正文中的显示格式固定为：

```html
<u><em>【联网补充｜非论文证据｜W001｜统计年度2025】……</em></u>
```

这使联网事实与论文证据在来源、审计和视觉上均保持隔离。

## 真实验证

`external-current-evidence-20260814-v3` 首次证明了 Responses API 可用，但同时选入了年度最终值、预计值和阶段值，并出现同年度近似指标口径冲突。因此该结果只作为问题样本，不作为最终输出。

收紧原子事实、口径状态、指标判重和搜索步数后，`external-current-evidence-20260814-v5` 成功生成 5 条 2025 年最终统计。来源均为长江三峡通航管理局实际打开的年度正式发布页面，包括：

- 三峡枢纽年通过量 1.73 亿吨；
- 三峡船闸年通过量 1.7 亿吨；
- 三峡升船机年客运量 63.2 万人次；
- 船闸与升船机合计运行 14415 闸（厢）次；
- 保障民生物资过坝 4614.48 万吨。

本次调用总计约 7.46 万 token。主要消耗来自搜索和页面上下文，因此联网层应按“时效缺口”触发，而不是对每篇论文常规执行。

## 当前边界

- 已验证来源 URL 确实被模型的搜索工具打开，但尚未在本地抓取网页并逐数字复核页面正文。
- 联网事实目前作为显式附加层展示，尚不允许改写论文机制分析或替代论文引用。
- 主报告仍保留论文证据的时间范围声明；加入联网层不等于把旧论文证据更新为新论文证据。

当前定性结论：论文写作的时效误判已被阻断，联网补充机制已完成真实可用性验证；若要把联网数字用于核心推论，下一步应增加页面正文快照和数值逐项核验，而不是扩大搜索数量。
