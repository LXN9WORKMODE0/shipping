# 可视化工作台 M3.4 运行治理实施记录

日期：2026-07-29

## 已实现

### 工作台 Job 治理统计

新增：

```text
GET /api/governance/summary
```

统计只读取 `workspace/_ui/jobs`，不会把同一次调用对应的底层 topic review、synthesis 或 pipeline run 再次累加。

返回：

- Job、活动 Job 和终态 Job 数。
- API 请求数。
- prompt、completion 和 total Token。
- 已结束 Job 累计耗时。
- 已处理论文成功数、失败数和失败率。
- 按 Card、单篇分析、跨论文综合、完整流程分组。
- 按冻结模型 profile 和请求模型分组。
- Job 与逐论文失败代码频次。

真实账本核对结果：

```text
工作台 Job：11
API 请求：160
总 Token：1,742,165
模型：deepseek-v4-pro
活动 Job：0
```

历史运行页继续显示 152 条 UI Job 与底层不可变 run；治理总量只统计其中 11 个工作台 Job，避免重复计费。

### 配置健康

系统状态页新增 9 项本地检查：

- Pipeline 入口。
- Python 解释器。
- workspace 可写性。
- `.env` 存在及语法。
- LLM 地址和凭据。
- MinerU 默认/显式地址和凭据。
- 默认模型 profile。
- 单篇分析配置。
- 跨论文综合配置。

检查不访问网络，不返回 URL、API Key 或 env 原值。

当前真实环境结果：

```text
正常：9
警告：0
错误：0
```

### 项目归档

新增：

```text
GET  /api/projects?include_archived=true
POST /api/projects/{project_id}/archive
POST /api/projects/{project_id}/restore
```

归档状态写入项目定义并推进 revision。归档项目：

- 从默认活动列表隐藏。
- 在归档列表中保留。
- 可通过直接 URL 阅读全部历史产物。
- 禁止元数据修改、导入、collection 冻结和所有新 Job。
- 有活动 Job 时不能归档。
- 恢复后重新开放原有操作。

归档不移动或删除任何来源和运行产物。

## 边界

- 统计是用量与失败事实，不估算货币费用。
- 健康检查不验证外部服务实时可达性。
- 归档是逻辑只读，不是压缩、导出或清理。
- 不自动删除历史 run、原始响应或论文来源。
