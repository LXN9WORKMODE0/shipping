# 14篇论文参考文献目录与草稿装配记录

## 目标

为综合运行 `ui-synthesis-20260729T041531-bda9207f` 的14篇输入论文建立独立、可审计的参考文献层，并把题录编号确定性装配到已有综述草稿。该阶段不重新解析PDF、不修改Card、Evidence或跨论文综合结果，也不调用LLM。

## 输入边界

- 项目：`workspace/_ui/projects/review-20260728/project.json`
- 综合输入快照：`workspace/_topic_syntheses/runs/ui-synthesis-20260729T041531-bda9207f/input/source_runs.jsonl`
- 本地题录原文：各论文 `normalized/document.md`
- 核验表：`config/references/review-20260728-14papers.json`
- 待装配草稿：`workspace/_review_drafts/runs/draft-14papers-20260729/review/review_draft.md`

项目论文池共有37篇，本次目录只处理综合输入快照中的14篇。论文身份用 `paper_id` 精确连接，不能按题名模糊匹配。

## 技术方法

### 1. 本地逐字段提取

提取器识别以下题录信息，并为每个字段保存Markdown行号：

- 首页作者行，包括 `文 / 作者`、`研究生`、空格拆分姓名、作者后附单位等形式。
- 全角字符、HTML标签和字符间空格破坏的DOI。
- 文章编号，并确定性派生年份、期号和连续页码。
- 首页内嵌的标准引用行。
- 学位类型、年份和学位授予单位。

题名取项目论文身份，不用MinerU合并后的中英文H1覆盖。

### 2. 显式核验覆盖

程序不从ISSN、DOI前缀或文件名猜期刊。Markdown缺失字段通过核验表补充；每个覆盖字段必须关联至少一个来源，来源必须提供URL或本地路径。覆盖与本地值冲突时，同时保存本地值和核验值。

本轮两个主要缺失案例直接查看了原PDF：

- 指标体系论文：首页给出 `中国水运 2007·10`、DOI和起始页44；PDF共2个连续正文页，确定为44-45页。
- 辅助决策系统论文：首页给出《交通与计算机》1997年第15卷第5期，次页和末页为19和22，确定为18-22页。

学位论文首页OCR的“武汉理大学”经原PDF扉页核验为“武汉理工大学”，该替换保留冲突记录。

### 3. 完整性合同

期刊论文基本字段：

`题名 + 作者 + 年份 + 期刊 + 页码 + 卷或期`

学位论文基本字段：

`题名 + 作者 + 年份 + 学位授予单位 + 学位类型`

DOI和卷号不是所有中文文献都具备，因此作为可选字段。缺少基本字段的论文仍进入目录，但状态为 `partial` 并写入缺失审计，不阻断其他论文。

### 4. 草稿装配

程序只识别草稿中已有的 `（证据来源：论文题名）` 标记：

1. 精确映射到综合输入快照的 `paper_id/paper_title`。
2. 先收集正文实际引用集合。
3. 按总目录顺序为实际引用文献连续编号。
4. 在证据来源和证据索引中加入编号。
5. 文末只输出实际引用文献。

题名不能精确映射、草稿没有来源标记或已有参考文献章节时，装配直接失败。

## 审视结论

参考文献链已经基本闭合：论文集合边界明确，题录字段可定位，补充字段有来源，缺失不会静默消失，现有草稿可以不调用LLM完成编号装配。

需要明确三点限制：

1. `complete` 是字段完整合同，不是书目来源权威等级。部分期刊名使用外部ISSN记录核验，后续正式投稿时仍可换成期刊官网或数据库一级记录。
2. 文章编号派生页码依赖中文期刊常见的“起始页-篇幅”编码规则，来源链中明确标为确定性派生，不伪装成Markdown直接文本。
3. 补齐引用不会修复当前草稿的内容问题。草稿仍存在“系统梳理”“学界共识”“实践表明”等超出定向样本边界的表达，以及个别把算法效率外推为通航能力的风险；这些属于下一轮正文审查，不应由参考文献阶段掩盖。
